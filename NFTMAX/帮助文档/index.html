HTML Structure


The html template uses Latest Bootstrap V5.2.1 with valid HTML5 tags. This theme has a responisve layout with 4 column support. All of the information in content area is nested within a class and comes with predefined classes.

Sass and Bootstrap


The package uses the latest version of bootstap and sass till now. 

bootstrap version ^5.2
sass version ^1.55.0

All of the sass files as well as bootstrap is included under

./assets
  |- /scss
    |- /...
    |- /...
    |- /...
    |- /...
    |- /...
    |- /...
    |- /vendor

Note: This project only uses the grid and container styles from Bootstrap. The other Bootstrap component and framework styles are not included as well as the Javascript files.


But if they are needed you can install Bootstrap via npm

npm i

This also install Sass as your projects dev dependency

Now you can include them inside

./assets
  |- /scss
    |- /vendor
      |- bootstrap.scss

For compiling your sass files open terminal and run 

npm run sass

Which is configured to check for the sass files inside ./assets/scss/ and output to ./assets/css.

You can customize the file path from your package.json file.


Fonts

By default, the template loads this font from Google Web Font Services, you can change the font with the one that suits you best. 


@import url('https://fonts.googleapis.com/css2?family=Mulish:wght@400;500;600;700;800;900&family=Poppins:wght@300;400;500;600;700&display=swap');

Jquery and javascript


This theme imports three types of Javascript files.

  • 1. jQuery
  • 2. Custom scripts (main.js)
  • 3. Some jQuery Based Plugins

All the js included under

./assets
  |- /js
    |- /...
    |- /...
    |- /...
    |- /vendor

The vendor folder includes all thrid-party scripts like jQuery and jQuery Based Plugins

The version of jQuery included is

jQuery version v2.1.3

All of the plugin initailization and implementation is included inside 

./assets
  |- /js
    |- /plugin.js

You can change any of the plugin behavior or functionality from the file.



These are the JS files that are loaded into templates in end of the Body Section.
